# 鉄板の極 — ULTRA REALISTIC COOKING 3D

ブラウザだけで動く、超リアル志向の 3D ステーキ調理シミュレータ。
`index.html` をダブルクリックで開くだけでプレイできます(ビルド・サーバー・ネット接続すべて不要)。

![4K対応 / Three.js / WebAudio]

## 遊び方

1. **注文を確認**(左上のオーダーカード)。「ミディアムレア」など目標の焼き加減が出る
2. **火力スライダー**でコンロを点火し、フライパンを予熱(180°C以上が目安)
3. **油をひく**(引かないと焦げ付いて焼き目が汚くなる)
4. **塩・こしょう**で下味(焼く前に振ると満点)
5. **肉をドラッグ**してフライパンへ → ジュゥゥ…!
6. パンの中の肉を**クリックすると返せる**。両面にきれいな焼き目(クラスト)をつける
7. **中心温度ゲージ**を見ながら火入れ。緑のゾーンが注文の狙い目
8. **取り出してまな板で休ませる**(余熱で中心温度が数度上がる=キャリーオーバー)
9. 皿にドラッグして盛り付け、**「提供する」**
10. 断面公開&採点(焼き加減・焼き目・下味・休ませ)。ランクSを狙え

バターを途中で入れると風味ボーナス。焦がすと減点、生で出すとお代なし。

## リアル要素(シミュレーション)

- パン温度の熱慣性(予熱・肉を置いた時の温度低下)
- 面ごとのメイラード反応(接地面だけが焼ける・texture がリアルタイムで褐変)
- 中心温度の熱伝導と、休ませ中の**キャリーオーバー(余熱)**
- 水分量に応じたシズル音(WebAudio でリアルタイム合成)・湯気・煙・油ハネ
- 焦げれば黒くなり、煙も黒くなる
- 断面の色は中心温度から算出(レア〜ウェルダン〜過加熱)

## 操作

| 操作 | 効果 |
|---|---|
| 肉をドラッグ | フライパン / まな板 / 皿 へ移動 |
| パンの中の肉をクリック | ひっくり返す |
| 背景をドラッグ | カメラ回転 |
| ホイール | ズーム |
| 右上「画質」 | HD / 2K / **4K** レンダリング切替 |

## 技術

- Three.js r128(`vendor/three.min.js` に同梱、MIT ライセンス)
- 外部アセットゼロ:木目・タイル・肉のサシ・クラスト・炎・煙、全テクスチャを Canvas でプロシージャル生成
- PBR マテリアル + ACES トーンマッピング + PCF ソフトシャドウ + PMREM 環境マップ
- カスタムシェーダによるパーティクル(煙・湯気・油ハネ、パーティクル毎のアルファ/色)
- 効果音は全て WebAudio で合成(シズル=帯域通過ノイズ、クラックル、提供ベル)
- 「4K」設定で内部レンダリング解像度を 3840px 相当まで引き上げ(GPU 性能に注意)

ゲーム内時間は 6 倍速(実時間 ~10 秒で片面が焼ける)。
